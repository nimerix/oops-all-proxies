# Proxxied Interface Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restructure the Proxxied client around a deck roster, a whole-sheet mat, a print setup panel and an always-visible export, without changing printed output.

**Architecture:** The React/Zustand client keeps its print pipeline (rendering, export and storage helpers) untouched. The shell, panels, dialogs and feedback components are rebuilt on shared design tokens, with four small stores (`ui`, `undo`, `previews`, `confirm`) and pure helpers (`deckGroups`, `artworkScope`, `sheetScale`, `plural`) that carry the testable logic. Each task leaves the app working and both test suites green.

**Tech Stack:** React 19, TypeScript 5.8, Zustand 5, hand-written CSS plus Tailwind 4 utilities, dnd-kit, lucide-react, Vitest (node environment), Playwright (Chromium and WebKit).

**Spec:** `docs/superpowers/specs/2026-11-14-ui-revamp-design.md`. Read all of it before starting any task. Baseline screenshots of the current interface are in `.artifacts/ui-revamp/baseline/`.

## Global Constraints

- Do not change anything in `server/`, or the behaviour of the client files that render, export or store: `renderCardImage.ts`, `canvasProcessing.ts`, `bleed*.ts`, `paintBleedBorders.ts`, `resolveBleedBorders.ts`, `printLayout.ts`, `printGuides.ts`, `cardSources.ts`, `ExportProxyPageToPdf.tsx`, `ExportImagesZip.ts`, `IndexedDBStorage.ts`, `cardRender.worker.ts` (all in `client/src/helpers/`).
- No new runtime dependency. Icons come from `lucide-react`.
- Keep these class names: `.sheet-scroller`, `.proxy-page`, `.card-grid`, `.card-menu`, `.card-control`.
- Keep these accessible names: "{name}, change artwork", "Actions for {name}", "Reorder {name}", "Flip {name}", "Upload back for {name}", "Back image for {name}", "Decklist", "Card language", "Add to deck", "Upload card images", "Upload MPC images", "MPCFill XML or text", "Paper size", "Columns", "Rows", "Fit maximum cards", "Bleed (mm)", "Spacing (mm)", "Border bleed", "Image edges", "Image corner radius (mm)", "Shadow removal (mm)", "Custom cardback", "Width (px)", "Resolution", "Pages per file", "Split PDF into smaller files", "Export fronts PDF", "Export backs PDF", "Export collated PDF", "Find a card", "Search", "Bleed for this card", "Card border bleed", "Card image edges", "Card image corner radius", "Card shadow removal", "Card bleed preview", "Bleed result", "Retry bleed preview", "Close artwork picker", "Cancel import", "Continue without saving".
- Keep these status strings exactly: "Saved in this browser", "Saving workspace…", "Changes not saved", "Temporary workspace · saving disabled".
- Colours come only from the role tokens in spec section 4.8. No hex, `rgb()` or Tailwind colour utility in a component file.
- No visible text under 12 px (`0.75rem`). Font weights 400, 500, 600 and 700 only. Font stack `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.
- Sentence case. Buttons start with a verb. No uppercase eyebrow labels, numbered section markers or taglines.
- Hover styling inside `@media (hover: hover)`. Movement, scale and blur only inside `@media (prefers-reduced-motion: no-preference)`. Transitions name their properties; never `transition: all`.
- Every dialog is a native `<dialog>` opened with `showModal()` that returns focus to its opener.
- Every change to the deck (`cards` and the four image maps in the cards store) made by a user action runs inside exactly one `deckEdit` call. Nothing records undo history by subscribing to the store.
- Dragging a card stays on its handle. Do not attach drag listeners to the card face.
- Browser tests may change how they reach a control. They may not weaken or delete an assertion about PDF contents, pixels, ZIP contents, saved data or cancellation.
- Comments only where a reader would otherwise be misled.
- Do not commit, push or switch branches. Work in the checkout as it is (branch `ui-revamp`).

## Review Focus

1. **Undo of an uploaded card with its own back.** Removing it and undoing must bring back both files, and both must survive a reload. Pinned in Task 1 (browser test).
2. **A workspace saved before the revamp.** No `zoomMode` or `twoSided` key, `exportCollated: true`, a relative `zoom` of 1.4. It must open at Fit page, two-sided, with every other setting intact. And a saved `twoSided: false` must not be overridden by `exportCollated: true`. Pinned in Task 1 (unit tests).
3. **Quantity minus on copies that are not adjacent.** `A, B, A` with minus on A must leave `A, B`. Pinned in Task 3 (unit test).
4. **Files dragged over the window while a dialog is open or a task is running.** The drop targets must not appear and the drop must do nothing. Dropping a PDF must show an error, not silence. Pinned in Task 3 (browser test).
5. **A phone with the bottom bar.** The last deck row, the last print setting and a toast must all be reachable and not covered by the bar at 390×844 and 320×640. Pinned in Task 2 (browser test).
